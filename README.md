# CropGuard AI

AI-powered crop leaf disease detection system using MobileNetV2 and FastAPI.

This project detects 24 plant disease classes from leaf images.

## Features
- Upload crop leaf images
- Detect plant diseases
- Predict disease with confidence score
- Support 24 disease classes
